Legend — how to read this page

  • Registry code — the A1-G2 coding-agent failure taxonomy (Observability Phase 2). Each guard/gate check maps to one code; a code with no current guard never appears here (not a gap in this page, a gap in guard coverage).
  • clean_completion — the ground-truth completion gate passed and the run's own harness signal was a genuine single-shot finish.
  • partial — the gate passed but the run didn't cleanly finish (e.g. hit its turn limit) — real work happened, but not a clean pass.
  • not_attempted — the gate failed specifically because the diff was empty — no real change was made.
  • catastrophic — the gate failed on a severe check (scope violation or a syntax-breaking edit), or the run itself broke (budget halt, context overflow, an infra call failure).
  • unknown — no completion-gate record exists for this branch at all.
  • Note: the uncertainty panel only has data once real coding-agent traffic has run with the langfuse_tracing flag on — it's off by default, so this panel may show few points most of the time.

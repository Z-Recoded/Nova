    Legend — how to read this page

    • Category — which retrieval routing category the query matched (identity, fiction, project, finance, technical, general).
    • Sources — which Second Brain files were retrieved as context for that answer.
    • Blend detected — whether a fiction query pulled context from more than one character's file. Only meaningful for fiction-category queries.
    • Avg latency (Benchmark Runs) — average response time across all 8 fixed golden queries in that run.
    • Blend rate — fraction of the 3 fiction-category golden queries specifically where blending was detected — not a fraction of all 8.
    • Category mismatches — how many golden queries were routed to a different category than expected. 0 is healthy; anything higher signals a routing regression.
    • Note: latency naturally varies a little run to run (LLM inference isn't perfectly deterministic) — watch for large jumps, not small noise.
    • Note: this page doesn't auto-refresh. Reload it after running a new benchmark to see the new entry.

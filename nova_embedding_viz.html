Legend — how to read this page

  • Position — chunks placed near each other have similar embeddings. Tight, separated clusters per character are healthy; characters whose clusters overlap in 2D are the ones production retrieval is most likely to blend together.
  • Color + shape — each of the 14 characters gets a fixed hue+shape combination (circles for the first 8, squares for the rest, reusing hues). With 14 categories, color alone isn't always colorblind-distinguishable between every pair — click a legend swatch to isolate one character if two look similar, or hover any point for its exact identity as text.
  • Other (muted gray) — the 426 non-character chunks (Second Brain notes, source files) that aren't tied to a specific character.
  • White ring — this chunk was actually returned by a real retrieval call for the query typed above, using the same logic nova_query.ask() uses in production.
  • Dashed outline — this chunk's file was involved in a blend event that already has a real DPO correction written (see logs/training_flags.jsonl).
  • Note: the projection is cached after the first load — click "Highlight" with a query to re-check overlays without waiting for a fresh projection.
